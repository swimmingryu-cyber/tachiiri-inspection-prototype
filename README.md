# 立入検査サポート Ver.0.1（操作確認用）

スマートフォンで試すための静的Webページです。サーバー側のデータベースは使わず、検査データを各端末のブラウザ内に保存します。公開されるのはこの試作ページのソースコードです。

## 公開準備

このフォルダーの中身を、新しい公開GitHubリポジトリにアップロードします。GitHubの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定すると、`main`ブランチへのアップロード後にHTTPSの公開URLが作成されます。

公開前に確認してください。リポジトリのソースコードは公開されます。実際の検査記録はサーバーへ送らず、入力した端末のブラウザ内だけに保存されます。

このページは試作です。仮の点検項目を含むため、正式な点検や法令適合判定、消防署への提出には使用しないでください。
