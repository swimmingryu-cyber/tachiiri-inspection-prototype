# 立入検査サポート Ver.0.1（操作確認用）

## 公開Web版

[立入検査サポートを開く](https://swimmingryu-cyber.github.io/tachiiri-inspection-prototype/)

スマートフォンでも、モバイル通信またはWi-Fi経由でアクセスできます。HTTPSで開いてください。

## 保存とプライバシー

検査データ・写真は入力した端末のブラウザ内（localStorage）に保存され、サーバーへ送信されません。端末間の同期・共有はありません。公開リポジトリのソースコードは誰でも閲覧できますが、検査記録は公開されません。

ブラウザのデータ消去や端末変更で記録が失われることがあります。アプリ自体にパスコード保護や暗号化はありません。完了記録は、完了から7日経過後にアプリを開いたとき削除されます。

## 注意事項

このページは操作確認用の試作で、仮の確認項目を含みます。正式な点検票、法令適合判定、消防署への提出には使用しないでください。
